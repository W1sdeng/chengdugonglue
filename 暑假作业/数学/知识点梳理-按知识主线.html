数

模块一 · 数与代数

主线：数（有理数 → 实数）→ 式（代数式 → 整式 → 分式 → 二次根式）→ 方程（一元一次 → 二元一次）→ 不等式 → 函数（一次函数）

▍全模块知识主线（先学"数"，再学"式"，用"式"列"方程与不等式"，最后上升为"函数"）
有理数→ 实数→ 代数式→ 整式→ 一元一次方程→ 二元一次方程组→ 不等式与不等式组→ 分式→ 二次根式→ 一次函数

衔接逻辑：① 先学会数的运算（有理数、实数），再把"用字母表示数"升级为代数式；② 把具体数字换成字母，就得到整式与分式，进而能"列式子找等量关系"；③ 含未知数的等式即方程（一元一次 → 二元一次），含不等号的即不等式；④ 当方程中的未知数固定时是"解"，当它随另一变量变化时，就上升为函数——方程是函数取特定值的情形，是"数"与"式"的最高归宿。

01

有理数（含有理数的运算）

七上 第1、2章
本讲知识脉络
正数与负数→ 数轴 / 相反数 / 绝对值→ 大小比较→ 加减乘除乘方→ 运算律与混合运算→ 科学记数法 / 近似数

知识衔接：有理数是初中数学的第一块基石。小学学的都是非负有理数，这里引入负数后把数的范围扩大到全体有理数；有理数的运算律（交换律、结合律、分配律）在后面的整式、实数、方程里会一直沿用，所以本讲务必学扎实。

核心概念

  • 正数与负数：用正、负数表示具有相反意义的量（如收入 +300 与支出 −120）。
  • 有理数分类：① 按定义：整数（正整数、0、负整数）与分数（正分数、负分数）；② 按符号：正有理数、0、负有理数。
  • 数轴：规定了原点、正方向、单位长度的直线；数轴上右边的数总比左边的大。
  • 相反数：只有符号不同的两个数；0 的相反数是 0。
  • 绝对值：数轴上表示数的点到原点的距离，|a| 永远是正数或 0。
  • 倒数：乘积为 1 的两个数互为倒数；0 没有倒数。
  • 乘方：aⁿ 表示 n 个 a 相乘，a 叫底数、n 叫指数、结果叫幂。
  • 科学记数法：把大数写成 a×10ⁿ 的形式（1 ≤ |a| < 10）。

重要公式与定理

①绝对值非负：|a| ≥ 0，|-a| = |a|
②加法交换律 a+b = b+a；结合律 (a+b)+c = a+(b+c)
③乘法交换律 a·b = b·a；结合律 (a·b)·c = a·(b·c)
④分配律 a(b+c) = ab+ac
⑤乘法法则：同号得正，异号得负，再把绝对值相乘
⑥除法法则：除以一个数等于乘它的倒数
⑦乘方符号：正数任何次幂为正；负数奇次幂为负、偶次幂为正
⑧混合运算顺序：先乘方 → 再乘除 → 后加减；有括号先算括号
⑨科学记数法 a×10ⁿ（1≤|a|<10），n = 整数位数 − 1

常见题型与解题方法

  1. 求相反数 / 绝对值 / 倒数：按定义直接写；求绝对值先看符号——正数绝对值是它本身，负数是它的相反数。
  2. 数轴比较大小：在数轴上标点，右边大于左边；或"正数 > 0 > 负数"快速判断。
  3. 混合运算：严格按顺序算，每一步写清楚，避免跳步出错；有理数加法先定符号再算绝对值。
  4. 由 |a| 求 a：|a| = m（m>0）时 a = ±m，两个解不要漏。
  5. 科学记数法互化：小数点移到第一位数字后，移动几位 n 就是几。
02

实数（平方根、立方根与无理数）

七下 第8章
本讲知识脉络
算术平方根 √a→ 平方根 ±√a→ 立方根 ∛a→ 无理数与实数分类→ 实数运算与大小比较

知识衔接：在有理数基础上发现 √2 这样的数"写不出来、说不尽"，于是把数域再次扩大成实数。实数分类要建立好，后面八下学二次根式时，√a 的一切运算法则都来自本讲的平方根性质。

核心概念

  • 算术平方根：正数 a 的算术平方根 √a（a ≥ 0），是非负数，满足 (√a)² = a。
  • 平方根：正数 a 的平方根是 ±√a（两个，互为相反数）；0 的平方根是 0；负数没有平方根。
  • 立方根：a 的立方根 ∛a；任意实数都有立方根（正数正、负数负、0 为 0）。
  • 无理数：无限不循环小数，如 π、√2、√3、0.1010010001…
  • 实数分类：实数 = 有理数（整数 + 分数）∪ 无理数。

重要公式与定理

①(√a)² = a（a ≥ 0）
②√(a²) = |a|（a≥0 时 = a；a<0 时 = −a）
③√a · √b = √(ab)（a,b ≥ 0）
④√a ÷ √b = √(a/b)（a ≥ 0，b > 0）
⑤(∛a)³ = a；∛(a³) = a
⑥常见无理数：π、√2、√3、√5、0.101001…
⑦实数运算律与有理数完全相同
⑧实数也有相反数与绝对值，意义与有理数一致

常见题型与解题方法

  1. 平方根 vs 算术平方根："9 的平方根"答 ±3；"√9"答 3。审题看清带不带正负号。
  2. 判断无理数：开方开不尽的数、含 π 的、构造的无限不循环小数都是无理数；分数（有限或循环小数）是有理数。
  3. 实数比较大小：① 平方法：√a 与 √b 比较，就看 a 与 b；② 估值法：√2 ≈ 1.414，√3 ≈ 1.732。
  4. 实数运算：先化简根号，再按有理数运算律合并计算。
03

代数式

七上 第3章
本讲知识脉络
用字母表示数→ 代数式的书写与意义→ 列代数式（文字 → 式子）→ 代数式求值

知识衔接：从"具体的数"到"用字母代表数"，是小学算术到中学代数的关键一跃。代数式是后续所有"式"（整式、分式、根式）的统称，也是列方程、列函数表达式的基本工具。

核心概念

  • 代数式：用运算符号（+、−、×、÷、乘方）把数或表示数的字母连接起来的式子，如 2x+3、a²。
  • 单项式：数与字母的乘积，如 3x、−5ab；单独一个数或字母也是单项式。
  • 系数与次数：单项式系数是数字因数，次数是所有字母指数之和。
  • 多项式：几个单项式的和；多项式的次数是次数最高项的次数。

重要公式与定理

①书写规范：数与字母相乘省略乘号且数字在前，如 3a；除法写成分数 a÷b = a/b
②系数是数字部分（含符号）；次数是各字母指数之和
③多项式的次数 = 最高次项的次数；整式 = 单项式 ∪ 多项式
④求值方法：先化简，再把字母的值代入计算（含整体代入）
⑤列式模型：路程=速度×时间，工作量=效率×时间

常见题型与解题方法

  1. 列代数式：抓关键词——"和差积商"、"多多少""几倍""平均"，如"x 的 2 倍与 3 的和"→ 2x+3。
  2. 行程 / 工程 / 面积列式：用字母表示速度、时间等，再按公式组合。
  3. 整体代入：已知 a+b=5，求 2(a+b)+1 = 11，把 a+b 当整体代入更省事。
04

整式（加减、乘法与因式分解）

七上 第4章 + 八上 第16、17章
本讲知识脉络（跨两个学期，主线连续）
同类项 / 合并同类项→ 去括号 / 整式加减→ 幂的运算→ 整式乘法（单项式×多项式）→ 乘法公式（平方差 / 完全平方）→ 因式分解（与乘法互为逆运算）

知识衔接：整式加减在七上，整式乘法与因式分解在八上——隔一个学期但实为同一条链：加减是"先会整理"，乘法与因式分解是"互逆的两面"（乘法是展开，因式分解是往回合并）。因式分解又为八上分式约分、八下二次根式化简服务。

核心概念

  • 同类项：所含字母相同且相同字母的指数也相同的项（与系数无关）。
  • 合并同类项：同类项系数相加，字母与字母的指数保持不变。
  • 去括号法则：括号前是"+"，去括号各项不变号；括号前是"−"，去括号各项都变号。
  • 乘法公式：平方差公式、完全平方公式——整式乘法的"快捷方式"。
  • 因式分解：把一个多项式化成几个整式的积，与整式乘法互为逆变形。

重要公式与定理（幂运算 + 乘法公式 + 因式分解）

①合并同类项：系数相加，字母与指数不变
②同底数幂相乘：aᵐ·aⁿ = am+n
③幂的乘方：(aᵐ)ⁿ = amn
④积的乘方：(ab)ⁿ = aⁿbⁿ
⑤同底数幂相除：aᵐ÷aⁿ = am−n（a≠0）
⑥零指数幂：a⁰ = 1（a≠0）
⑦平方差公式：(a+b)(a−b) = a²−b²
⑧完全平方公式：(a±b)² = a²±2ab+b²
⑨提公因式法：ab+ac = a(b+c)
⑩公式法：a²−b² = (a+b)(a−b)；a²±2ab+b² = (a±b)²

常见题型与解题方法

  1. 整式加减：一看同类项，二去括号（注意负号变号），三合并。
  2. 幂运算：先判断"同底数幂、幂的乘方还是积的乘方"再套公式；易混：aᵐ·aⁿ 指数相加，而 (aᵐ)ⁿ 指数相乘。
  3. 乘法公式运用：识别"哪是 a、哪是 b"，如 99×101 = (100−1)(100+1) = 10000−1 = 9999。
  4. 因式分解两步走：① 先提公因式（能提就提）；② 再看能否用公式法；③ 检查是否分解彻底（结果必须是整式的积）。
  5. 化简求值：先展开合并再代入，比直接代入更省力更不易错。
05

一元一次方程

七上 第5章
本讲知识脉络
方程与方程的解→ 等式的性质（移项依据）→ 移项 / 合并同类项→ 去括号 / 去分母→ 解一元一次方程→ 列方程解应用题

知识衔接：方程是"算术逆思路"的产物——把未知数设出来当已知参与运算。一元一次方程是一切方程的基础：二元一次方程组要"化为一元一次"来解，分式方程去分母后也变回一元一次方程，一次函数求值本质上也是解方程。

核心概念

  • 方程：含有未知数的等式。一元一次方程：只含一个未知数、未知数最高次数为 1 的整式方程。
  • 方程的解：使方程左右两边相等的未知数的值。
  • 等式性质：两边同加同减、同乘同除（除数不为 0），等式仍成立——是移项、系数化 1 的依据。
  • 移项：把项从等号一边移到另一边并变号。

重要公式与定理

①等式性质 1：a=b ⇒ a±c = b±c
②等式性质 2：a=b ⇒ ac = bc；a÷c = b÷c（c≠0）
③解方程五步：去分母 → 去括号 → 移项 → 合并同类项 → 系数化为 1
④去分母时每项都乘分母最小公倍数（含不含分母的项）
⑤列方程步骤：设未知数 → 找等量关系 → 列方程 → 解方程 → 检验作答
⑥利润 = 售价 − 进价；利润率 = 利润 ÷ 进价 ×100%

常见题型与解题方法

  1. 解方程五步歌：有分母先乘最小公倍数，有括号先去括号，然后移项（变号）、合并、系数化 1，最后代回检验。
  2. 行程问题：相遇：甲路程+乙路程=总路程；追及：路程差 = 距离。
  3. 工程问题：工作效率 × 工作时间 = 工作量，常把总量看作 1。
  4. 配套 / 销售 / 方案：用含 x 的式子表示各量，按等量关系列方程或比较两个式子。
06

二元一次方程组

七下 第10章
本讲知识脉络
二元一次方程（无数组解）→ 二元一次方程组（求公共解）→ 代入消元法→ 加减消元法→ 消元 → 化为一元一次方程→ 应用（两个未知数两个等量关系）

知识衔接：核心思想是"消元"——把两个未知数消成一个，问题回到上一讲的一元一次方程。这体现了初中代数最重要的"转化思想"：把新问题转化为已会的问题，后面分式方程、二次根式也用同样的思想。

核心概念

  • 二元一次方程：含两个未知数且未知数次数都是 1 的方程，有无数组解。
  • 二元一次方程组：几个方程合成一组，公共解才是方程组的解。
  • 消元思想：通过代入或加减把二元 → 一元，即"消元"。
  • 代入消元法：把一个方程变成"y = 含 x 的式子"再代入另一方程。
  • 加减消元法：系数相等相减、系数互为相反数相加，消去某一未知数。

重要公式与定理

①二元一次方程一般式 ax+by = c（a、b≠0）
②代入消元步骤：变式 → 代入 → 解一元一次 → 回代
③加减消元：系数相同相减、相反相加；成倍数先扩倍再加减
④检验：解代回原方程组两个方程都成立才正确
⑤应用模型：鸡兔同笼（头数/脚数）、行程、比例分配、数字问题

常见题型与解题方法

  1. 选消元方法：某未知数系数是 ±1 用代入法最方便；系数相等/相反/成倍数用加减法。
  2. 列方程组：两个未知数必须找两个等量关系，设 x、y 后翻译成两个方程。
  3. 含参问题：参数当常数，先解出 x、y（含参数），再按条件列关于参数的方程。
07

不等式与不等式组

七下 第11章
本讲知识脉络
不等式与不等式的解→ 不等式的性质（与等式性质异同）→ 解一元一次不等式→ 数轴表示解集→ 解不等式组（求公共解集）→ 应用（最多 / 至少 / 方案设计）

知识衔接：不等式像"会拐弯的方程"：解法几乎一样，唯独乘除负数时方向会变，注意与方程对比记忆。不等式还会和一次函数联手——八下"一次函数与不等式"：图象在 x 轴上方（下方）的部分正是解不等式。

核心概念

  • 不等式：用不等号（>、<、≥、≤）连接的式子。
  • 解集：使不等式成立的未知数的取值范围，用数轴表示更直观。
  • 不等式组：几个不等式组成，解集是各解集的公共部分。
  • 整数解：解集范围内的整数，常作小题考点。

重要公式与定理

①性质 1：a>b ⇒ a±c > b±c（同加同减，方向不变）
②性质 2：a>b 且 c>0 ⇒ ac > bc（乘除正数，方向不变）
③性质 3：a>b 且 c<0 ⇒ ac < bc（乘除负数，方向改变！）
④口诀：同大取大；同小取小；大小小大中间找；大大小小找不到
⑤数轴表示：>、≥ 向右，<、≤ 向左；≥、≤ 实心点，>、< 空心圈

常见题型与解题方法

  1. 解不等式：步骤同方程，唯一注意——两边乘或除以负数时要改变不等号方向，这是失分重灾区。
  2. 解不等式组：分别解出每个不等式，画在同一条数轴上找公共部分。
  3. 求整数解 / 最值：先求解集再数整数；"至少""不超过"要会列"≥、≤"。
  4. 方案设计：设购买量 x，列出费用（或利润）关于 x 的不等式，求 x 范围后分类给出方案。
08

分式

八上 第18章
本讲知识脉络
分式的概念与意义→ 分式基本性质→ 约分（化最简分式）→ 通分（化同分母）→ 分式四则运算→ 分式方程（去分母 → 检验增根）→ 应用（工程 / 行程 / 销售）

知识衔接：分式 = "分母含字母的分数"。把小学分数运算的"约分、通分"搬到"分母是整式"上即可。分式方程去分母后变整式方程，但可能产生使分母为 0 的"增根"，所以必须检验——这是与一元一次方程最大的不同。

核心概念

  • 分式：A/B（B 含字母且 B≠0）；A 是分子、B 是分母。
  • 分式有意义：分母不为 0；分式值为 0：分子为 0 且分母不为 0。
  • 最简分式：分子分母没有公因式的分式（相当于分数的"最简分数"）。
  • 增根：去分母时可能乘 0，产生使最简公分母为 0 的"假根"，必须舍去。

重要公式与定理

①基本性质：A/B = (A×M)/(B×M)（M≠0）
②乘法：A/B · C/D = AC/(BD)
③除法：A/B ÷ C/D = A/B · D/C = AD/(BC)
④同分母加减：A/B ± C/B = (A±C)/B
⑤异分母加减：先通分再按同分母加减
⑥分式方程解法：去分母 → 解整式方程 → 检验（代入最简公分母，为 0 则舍去）

常见题型与解题方法

  1. "有意义 / 值为 0"：意义看分母≠0；值为 0 要"分子为 0 且分母≠0"双条件。
  2. 化简求值：先约分再代入（代入时不能取使分母为 0 的值）。
  3. 解分式方程：最后一步检验不能省；应用题还要检验是否符合实际（如人数是整数）。
  4. 增根求参数：让最简公分母为 0 的 x 即增根，代回整式方程反求参数。
09

二次根式

八下 第19章
本讲知识脉络
二次根式概念（√a，a≥0）→ 性质：(√a)²=a、√(a²)=|a|→ 最简二次根式→ 乘除运算→ 加减（合并同类二次根式）→ 化简求值与综合应用

知识衔接：二次根式把七下"实数"里的 √a 单独系统研究。它运算和分式、整式很像：加减要"同类"，乘除有公式，化简求"最简"。它还是八下勾股定理的"好帮手"——求斜边长、无理数边长都要用到根式运算。

核心概念

  • 二次根式：形如 √a（a≥0）的式子，有双重非负性：被开方数 a ≥ 0，且 √a ≥ 0。
  • 最简二次根式：① 被开方数不含分母；② 被开方数不含能开得尽方的因数（式）。
  • 同类二次根式：化简后被开方数相同的根式（类似同类项）。
  • 分母有理化：把分母中的根号化去。

重要公式与定理

①双重非负性：√a 中 a≥0 且 √a≥0
②(√a)² = a（a ≥ 0）
③√(a²) = |a|（平方再开方看绝对值，易错点）
④√a · √b = √(ab)（a,b ≥ 0）
⑤√a ÷ √b = √(a/b)（a ≥ 0，b > 0）
⑥加减：先化最简，再合并同类二次根式
⑦分母有理化：1/√a = √a/a

常见题型与解题方法

  1. 化简：把被开方数分解成"平方因数 × 其他"，平方因数开出来，如 √12 = √(4×3) = 2√3。
  2. 求取值范围：被开方数 ≥ 0，如 √(x−2) 要求 x ≥ 2。
  3. √(a²) 化简：先加绝对值再判断正负，如 √((−3)²) = |−3| = 3。
  4. 混合运算：先化最简再合并；与勾股定理结合求边长时按公式代入计算。

一次函数

八下 第22章
本讲知识脉络
变量与常量 / 函数概念→ 自变量的取值范围→ 正比例函数 y=kx→ 一次函数 y=kx+b（图象与性质）→ 待定系数法求解析式→ 一次函数与方程、不等式→ 应用（行程 / 方案）

知识衔接（全模块"收网"之讲）：一次函数把前面所有代数知识串成一条线——解析式 y=kx+b 是"含两个参数的代数式"，求 k、b 用待定系数法（实质是解方程组），图象与 x 轴交点的横坐标正是对应一元一次方程的解，图象在 x 轴上方（或下方）的部分对应不等式的解集。函数是研究"关系"的学问，是高中数学函数学习的起点。

核心概念

  • 函数：变化过程中，对于 x 的每一个确定值，y 都有唯一确定的值与之对应。
  • 一次函数：y = kx+b（k、b 是常数，k≠0）；k 决定增减趋势，b 是与 y 轴交点的纵坐标。
  • 正比例函数：y = kx（k≠0），是 b=0 的特殊一次函数，图象过原点。
  • 待定系数法：设解析式 → 代点列方程（组）→ 解出 k、b → 写回解析式。
  • 数形结合：解析式、图象、表格是同一个函数三种表示，可互相转化。

重要公式与定理

①一次函数一般式：y = kx+b（k≠0）；b=0 即正比例函数 y=kx
②k>0：图象上升，y 随 x 增大而增大；k<0：图象下降，y 随 x 增大而减小
③b>0：交 y 轴正半轴；b<0：交负半轴；b=0 过原点
④图象是直线，两点确定一条直线（常取与 x、y 轴交点）
⑤待定系数法四步：设 → 代 → 解 → 写
⑥与 x 轴交点（令 y=0）：x = −b/k
⑦两直线平行 ⇔ k₁=k₂ 且 b₁≠b₂；重合 ⇔ k₁=k₂ 且 b₁=b₂
⑧两直线交点 = 方程组 {y=k₁x+b₁; y=k₂x+b₂} 的解
⑨一次函数与不等式：kx+b>0 ⇔ 图象在 x 轴上方的部分

常见题型与解题方法

  1. 求解析式：给两点 → 待定系数法解方程组；给一点且正比例 → 求 k；给 k 和一点 → 只求 b。
  2. 点在不在图象上：把横坐标代入求 y，与给出的纵坐标比较。
  3. 图象性质题：看 k、b 符号判断图象经过的象限；或由图象判断 k、b 符号。
  4. 行程 / 分段应用：找两点求解析式，再分段讨论（注意分段函数写法）。
  5. 与方程、不等式综合：交点即方程解；比较两函数大小即"谁的图象在上面"→ 解对应不等式。

几何图形初步（点、线、面、角）

七上 第6章
本讲知识脉络
立体图形 → 平面图形→ 点、线、面、体→ 直线 / 射线 / 线段→ 线段的中点→ 角与角的度量→ 余角 / 补角 / 角平分线

知识衔接：初中几何的"入门课"。线段中点、角平分线、余角补角这三样基本功，在后面平行线、三角形、全等的证明里反复使用，属于"工具性知识"。

核心概念

  • 立体图形与平面图形：从实物中抽象出几何体（圆柱、圆锥、棱柱、球），再认识展开图与视图。
  • 点线面体：点动成线、线动成面、面动成体；几何体由面围成。
  • 直线、射线、线段：直线无端点向两方延伸；射线有一个端点；线段有两个端点。
  • 角：两条射线（边）共端点（顶点）组成；度量单位 1°=60′，1′=60″。
  • 余角补角：和为 90° 互余，和为 180° 互补。

重要公式与定理

①两点确定一条直线（直线公理）
②两点之间，线段最短
③中点：M 是 AB 中点 ⇒ AM = MB = AB/2
④角度制：1° = 60′，1′ = 60″
⑤同角（或等角）的余角相等；同角（或等角）的补角相等
⑥角平分线：OC 平分 ∠AOB ⇒ ∠AOC = ∠COB = ∠AOB/2

常见题型与解题方法

  1. 线段长度计算：画图标注，用中点 + 和差关系列式，如 AB = AC + CB，AM = AB − MB。
  2. 角的换算：度分秒"六十进制"：化大单位×60、化小单位÷60，如 1.5° = 90′。
  3. 余角补角：直接"90° − α""180° − α"；利用"等角的余角相等"推角相等。
  4. 图形计数：数线段/角用规律 n(n−1)/2（n 为端点个数）。
02

相交线与平行线

七下 第7章
本讲知识脉络
相交线（对顶角、邻补角）→ 垂线 / 垂线段最短→ 三线八角（同位角、内错角、同旁内角）→ 平行线的判定→ 平行线的性质→ 平移 / 命题定理

知识衔接：本讲是初中"几何推理"的起点——第一次正式学习"判定（由角推平行）"与"性质（由平行推角）"，这是以后所有几何证明的基本套路。角的计算能力（余补角、对顶角）在这里大派用场。

核心概念

  • 对顶角：两条直线相交形成的对角；邻补角：相邻且互补的两个角。
  • 垂线：夹角 90° 时两直线垂直；垂线段最短，点到直线距离即垂线段长度。
  • 三线八角：两条直线被第三条直线（截线）所截，产生同位角（F 形）、内错角（Z 形）、同旁内角（U 形）。
  • 判定与性质：判定"由角到线"，性质"由线到角"，方向恰好相反。

重要公式与定理

①对顶角相等；邻补角互补（∠1+∠2 = 180°）
②过一点有且只有一条直线与已知直线垂直
③垂线段最短（点到直线距离）
④判定 1：同位角相等 ⇒ 两直线平行
⑤判定 2：内错角相等 ⇒ 两直线平行
⑥判定 3：同旁内角互补 ⇒ 两直线平行
⑦平行公理推论：平行于同一直线（或垂直于同一直线）的两直线平行
⑧性质 1：两直线平行 ⇒ 同位角相等
⑨性质 2：两直线平行 ⇒ 内错角相等
⑩性质 3：两直线平行 ⇒ 同旁内角互补
⑪平移：对应线段平行（或共线）且相等，对应点连线平行且相等

常见题型与解题方法

  1. 三线八角找角：先找截线（同时与两条直线相交的线），再按 F/Z/U 形判断角的位置关系。
  2. 角的计算：平行线背景下，用"内错角相等""同旁内角互补"把未知角转化为已知角，注意 180° 的使用。
  3. "拐点问题"（折线）：过折点作平行线，把大角"切开"转化为两组内错角 / 同旁内角。
  4. 证明题：先写"∠1=∠2（已知）"，结合判定/性质一步步推，每一步理由写在后面。

平面直角坐标系

七下 第9章
本讲知识脉络
有序数对确定位置→ 坐标轴 / 原点 / 象限→ 点的坐标（横、纵坐标）→ 关于坐标轴的对称 / 到轴的距离→ 点的平移（坐标变化）→ 坐标与图形面积

知识衔接：坐标系是"数与形"之间的翻译官——用一对数字（坐标）描述一个位置。本讲的对称、平移坐标规律，将在八上轴对称、八下一次函数图象中被直接使用，务必记牢。

核心概念

  • 平面直角坐标系：互相垂直、原点重合的两条数轴（x 轴、y 轴）构成。
  • 点的坐标：(a, b)，a 为横坐标、b 为纵坐标，先横后纵。
  • 象限：两轴将平面分成四个象限，坐标轴上的点不属于任何象限。
  • 有序数对：(a,b) 与 (b,a) 顺序不同位置不同，故"有序"。

重要公式与定理

①x 轴上点纵坐标 = 0；y 轴上点横坐标 = 0；原点 (0,0)
②各象限符号：一 (+,+)、二 (−,+)、三 (−,−)、四 (+,−)
③关于 x 轴对称：横不变纵相反 (a,b)→(a,−b)
④关于 y 轴对称：纵不变横相反 (a,b)→(−a,b)
⑤关于原点对称：横纵都相反 (a,b)→(−a,−b)
⑥点 (a,b) 到 x 轴距离 = |b|，到 y 轴距离 = |a|
⑦平移规律：左右平移变 x（右加左减），上下平移变 y（上加下减）
⑧水平/竖直两点距离 = 横坐标差或纵坐标差的绝对值

常见题型与解题方法

  1. 写坐标：过点向两轴作垂线，垂足读数即坐标；注意象限符号。
  2. 对称与平移：背熟三条对称规律 + 平移口诀"右加左减 x，上加下减 y"。
  3. 求图形面积：把底取在坐标轴上（或补成矩形），用坐标差的绝对值作底和高。
  4. 到坐标轴距离："到 x 轴距离看纵坐标绝对值"，易反着记错，注意区分。

三角形

八上 第13章
本讲知识脉络
三角形概念与分类→ 三边关系（不等式）→ 内角 / 外角定理→ 高、中线、角平分线→ 稳定性 / 多边形内角和

知识衔接：三角形是几何的核心"积木"。它的内角和、外角定理在求角中反复使用；三边关系是"是否存在三角形"的判据；高、中线、角平分线三条线，分别在勾股（高）、面积（中线）、全等证明（角平分线）中扮演关键角色。

核心概念

  • 三角形：三条线段首尾顺次相接组成的图形。按角分：锐角、直角、钝角三角形；按边分：等边、等腰、不等边三角形。
  • 三边关系：任意两边之和大于第三边（三角形存在的条件）。
  • 外角：一边与另一边延长线组成的角；每个外角与相邻内角互补。
  • 三条重要线段：高（顶点到对边垂线）、中线（顶点到对边中点）、角平分线（顶点到对边角的平分线）。
  • 稳定性：三角形形状唯一确定，多边形不稳定（可加对角线加固）。

重要公式与定理

①三边关系：b−c < a < b+c（两边之差小于第三边，和大于第三边）
②内角和定理：三角形内角和 = 180°
③外角定理：外角 = 不相邻两内角之和，且大于不相邻的任一内角
④直角三角形的两锐角互余；直角边 < 斜边
⑤n 边形内角和 = (n−2)×180°
⑥多边形外角和恒 = 360°（与边数无关）
⑦中线把三角形分成面积相等的两部分；三条中线交于重心

常见题型与解题方法

  1. 判断能否构成三角形：只需看"最长边 < 另两边之和"即可。
  2. 已知两边求第三边范围：|a−b| < c < a+b，再结合整数条件定取值。
  3. 求角：先内角和 180° 列方程，或用外角定理"外角 = 两内角之和"转化。
  4. 多边形：边数 n 与内角和互求 (n−2)×180°；外角和 360° 常用来求边数。

全等三角形

八上 第14章
本讲知识脉络
全等形 / 对应元素→ 全等三角形的性质→ 判定：SSS / SAS / ASA / AAS→ 直角三角形判定 HL→ 角的平分线（性质与判定）→ 应用（证明线段、角相等）

知识衔接：全等是"能重合"的图形关系，是证明"线段相等、角相等"的最常用武器。后面的轴对称、平行四边形证明，本质都是先证全等再得结论。熟练识别五种判定，是初中几何的重中之重。

核心概念

  • 全等形：能够完全重合的两个图形；重合的顶点叫对应顶点，重合的边叫对应边。
  • 全等三角形性质：对应边相等、对应角相等。
  • 五种判定：SSS、SAS（两边夹一角）、ASA（两角夹一边）、AAS、HL（仅直角三角形）。
  • 角平分线性质与判定：性质"到两边距离相等"；判定"到两边距离相等的点在角平分线上"——互为逆定理。

重要公式与定理

①性质：△ABC ≌ △DEF ⇒ 对应边相等、对应角相等
②SSS：三边对应相等 ⇒ 全等
③SAS：两边及夹角对应相等 ⇒ 全等
④ASA：两角及夹边对应相等 ⇒ 全等
⑤AAS：两角及其中一角的对边对应相等 ⇒ 全等
⑥HL：斜边和一条直角边对应相等的直角三角形全等
⑦角平分线性质：角平分线上的点到角两边距离相等
⑧角平分线判定：到角两边距离相等的点在这个角的平分线上
⑨全等三角形周长、面积分别相等

常见题型与解题方法

  1. 证全等三步套路：① 找已知条件（含公共边、公共角、对顶角等隐含条件）；② 缺什么补什么（角相等用平行线性质，边相等用中点/角平分线）；③ 选对判定方法。
  2. SAS 陷阱："边边角（SSA）"不能判定全等！两边和一非夹角不行。
  3. 构造辅助线：证线段之和用截长补短、倍长中线构造全等、过角平分线作垂线段。
  4. 角平分线模型：看到角平分线 + 作垂线段（出现 HL 全等），或延长构造等腰。

轴对称

八上 第15章
本讲知识脉络
轴对称图形 / 两个图形成轴对称→ 对称轴的性质→ 线段垂直平分线→ 画轴对称图形（含坐标表示）→ 等腰三角形（三线合一）→ 等边三角形 / 30° 直角三角形

知识衔接：轴对称既是"图形变换"，又引出等腰三角形这一重要工具。七下的"关于坐标轴对称"在此升级为一般对称；垂直平分线性质与角平分线性质在证明中地位相当。将军饮马（最短路径）更是综合与实践板块的主角。

核心概念

  • 轴对称图形：一个图形沿一条直线折叠，直线两旁部分互相重合，该直线叫对称轴。
  • 轴对称性质：对称轴是任何一对对应点所连线段的垂直平分线。
  • 垂直平分线：垂直于一条线段并且平分它的直线。
  • 等腰三角形：两腰相等，两底角相等（等边对等角），顶角平分线、底边中线、底边高"三线合一"。
  • 等边三角形：三边相等的等腰三角形，有 3 条对称轴。

重要公式与定理

①对称轴是任意一对对应点连线的垂直平分线
②垂直平分线性质：线上的点到线段两端点距离相等
③垂直平分线判定：到线段两端点距离相等的点在其垂直平分线上
④等腰三角形：等边对等角；等角对等边（判定）
⑤"三线合一"：顶角平分线 = 底边中线 = 底边上的高
⑥等边三角形：三边相等、三角各 60°；有一个角 60° 的等腰三角形是等边三角形
⑦30° 直角三角形：30° 角所对的直角边等于斜边的一半

常见题型与解题方法

  1. 垂直平分线求周长：利用"线上点到两端距离相等"把未知边转化为已知边再相加。
  2. 等腰分类讨论：① 已知角可能是顶角或底角；② 已知边可能是腰或底——两种情况分别算并检验能否构成三角形。
  3. 三线合一反用：知"等腰 + 三线中一线"可推其他两线；常配合勾股定理求高。
  4. 将军饮马最短路径：作点关于直线的对称点，连接另一点与对称点，交点即最短路线的拐点。

勾股定理

八下 第20章
本讲知识脉络
勾股定理（a²+b²=c²）→ 勾股定理的证明（面积法）→ 勾股定理逆定理（判断直角）→ 勾股数→ 应用：求边长 / 折叠 / 最短路径 / 测量

知识衔接（数与形的桥梁）：勾股定理用代数关系（三边平方关系）精确刻画几何图形（直角三角形），是"数形结合"的典范。它大量使用二次根式运算（求边长开方），为下一讲平行四边形中的对角线长度、等腰三角形的高提供了计算工具。

核心概念

  • 勾股定理：直角三角形两直角边 a、b 的平方和等于斜边 c 的平方。
  • 逆定理：若三角形三边满足 a²+b²=c²，则它是直角三角形（c 所对角为直角）。
  • 勾股数：满足 a²+b²=c² 的三个正整数，如 3、4、5。
  • 互逆命题：把一个命题的题设与结论互换得逆命题，原命题与逆命题互为逆命题。

重要公式与定理

①勾股定理：a² + b² = c²（c 为斜边，c 最大）
②求直角边：a = √(c²−b²)
③逆定理：a²+b² = c² ⇒ 三角形为直角三角形
④常用勾股数：(3,4,5)(5,12,13)(6,8,10)(7,24,25)(8,15,17)(9,40,41)
⑤特殊直角三边比：等腰直角 1:1:√2；30° 直角 1:√3:2
⑥立体最短路径：把圆柱/长方体表面展开成平面，用勾股求线段长

常见题型与解题方法

  1. 求边长：分清哪条是斜边，代入 a²+b²=c² 解方程（结果保留根号或最简二次根式）。
  2. 判断直角三角形：计算最大边的平方，与另两边平方和比较，不要只算一组。
  3. 折叠问题：设所求为 x，把折叠相等的边标出来，在直角三角形中列勾股方程。
  4. 蚂蚁爬行最短：展开侧面 → 找直角 → 用勾股求直线距离；长方体展平有三种路径要比较取最小。
  5. 实际应用：测距离（河宽、旗杆高）时构造直角三角形再套公式。

平行四边形（含矩形、菱形、正方形）

八下 第21章
本讲知识脉络
平行四边形的性质→ 平行四边形的判定→ 矩形（直角 + 等对角线）→ 菱形（四边等 + 对角线垂直）→ 正方形（集大成者）→ 三角形中位线

知识衔接（几何模块收官）：平行四边形是三角形知识的"总应用"——性质与判定常靠全等三角形证明。矩形、菱形、正方形是特殊平行四边形，关系是"包含"：正方形 ⊂（既是矩形又是菱形）。对角线、中位线计算常用勾股定理与一次函数综合。

核心概念

  • 平行四边形：两组对边分别平行的四边形；对角线互相平分。
  • 矩形：有一个角是直角的平行四边形，对角线相等。
  • 菱形：有一组邻边相等的平行四边形，对角线互相垂直且平分一组对角。
  • 正方形：四边相等、四个直角的四边形，集矩形与菱形性质于一身。
  • 三角形中位线：连接三角形两边中点的线段，平行于第三边且等于它的一半。

重要公式与定理

①平行四边形性质：对边平行且相等；对角相等、邻角互补；对角线互相平分
②判定 1：两组对边分别平行 / 分别相等
③判定 2：一组对边平行且相等；或两组对角分别相等
④判定 3：对角线互相平分的四边形是平行四边形
⑤矩形：四角直角、对角线相等且平分；判定（一角直角或对角线相等的平行四边形）
⑥菱形：四边相等、对角线互相垂直且平分对角；判定（邻边相等或对角线垂直）
⑦菱形面积 = 对角线乘积的一半 = 底×高
⑧正方形：四边相等、四角直角、对角线相等垂直平分且平分对角
⑨三角形中位线定理：DE∥BC 且 DE = BC/2
⑩平行四边形、矩形、菱形、正方形面积均为 S = 底×高

常见题型与解题方法

  1. 证明平行四边形：从五个判定中选最顺手的——通常"一组对边平行且相等"最快（只需证一次全等）。
  2. 矩形/菱形/正方形：先证是平行四边形，再加"一个特殊条件"；或由对角线、边、角的特征直接判定。
  3. 菱形面积：给对角线直接用乘积一半；给边长和高用底×高。
  4. 中位线：看到中点想中位线（连中点作辅助线），用于证明平行、面积平分。
  5. 综合题：平行四边形 + 一次函数（求顶点坐标、求面积），用坐标系知识列式求解。

01

数据的收集、整理与描述

七下 第12章
本讲知识脉络
全面调查 vs 抽样调查→ 总体 / 个体 / 样本 / 样本容量→ 统计表整理→ 条形图 / 扇形图 / 折线图→ 频数与频率→ 直方图（分组统计）

知识衔接：统计的第一步是"想办法拿到数据"。本讲学会的"样本"概念、图表读法，是下一讲"数据分析"的原料来源；扇形图圆心角、频率的计算直接服务于下一讲。

核心概念

  • 全面调查：对所有对象调查，结果精确但费时费力；抽样调查：从部分（样本）推断整体（总体）。
  • 总体 / 个体 / 样本 / 样本容量：考察对象的全体、每个对象、抽取的部分、样本中个体的数目（无单位）。
  • 频数与频率：每个小组内数据的个数叫频数；频率 = 频数 ÷ 数据总数。
  • 直方图：分组统计，横轴是数据（按组距分组），纵轴是频数，直观展示分布。

重要公式与定理

①抽样原则：样本要有代表性与随机性，容量要足够大
②扇形圆心角 = 该组百分比 × 360°
③频数之和 = 数据总数；频率 = 频数 ÷ 总数
④组数 = 极差 ÷ 组距（结果向上取整）
⑤条形图看数量、折线图看趋势、扇形图看占比、直方图看分布

常见题型与解题方法

  1. 选调查方式：范围小、要求精确用全面调查（如人口普查）；范围大、有破坏性用抽样调查（如检验灯泡寿命）。
  2. 补全统计图：由扇形图求总人数，或由条形图推百分比，再补全另一图。
  3. 读直方图：纵轴频数相加得总数，注意"边界值归属哪一组"的约定。
  4. 样本推断总体：用样本中某类占比 × 总体总数，估算总体中该类数量。
02

数据的分析

八下 第23章
本讲知识脉络
平均数（算术平均数）→ 加权平均数→ 中位数 / 众数→ 极差 / 方差（稳定性）→ 用样本估计总体

知识衔接：上一讲把数据"画出来"让人看得见，这一讲把数据"算成几个数"让人抓得住重点。平均数受极端值影响，中位数、众数不受——实际问题（工资水平、身高）常要用中位数更合理。方差大小决定"稳不稳"，常用于比较两个选手、两台机器的稳定性。

核心概念

  • 平均数：所有数据之和 ÷ 数据个数。
  • 加权平均数：各数据乘以各自的权（重要性）再求和除以权之和。
  • 中位数：把数据从小到大排序后最中间的数（偶数个取中间两个的平均）。
  • 众数：出现次数最多的数据（可能不止一个）。
  • 方差：各数据与平均数差的平方的平均数，越小越稳定。

重要公式与定理

①平均数：x̄ = (x₁+x₂+…+xₙ)/n
②加权平均数：x̄ = (x₁f₁+x₂f₂+…)/(f₁+f₂+…)
③中位数：排序后，奇数个取中间；偶数个取中间两数平均值
④众数：出现次数最多的数据
⑤极差 = 最大值 − 最小值
⑥方差：s² = [(x₁−x̄)²+(x₂−x̄)²+…+(xₙ−x̄)²]/n，方差越小越稳定
⑦用样本平均数、样本方差估计总体的平均水平与波动

常见题型与解题方法

  1. 求"三数"：求中位数先排序（从大到小或从小到大都行）；求众数统计出现次数。
  2. 判断稳定性：比较方差，方差小的更稳定（如两名射击选手选方差小的）。
  3. 选统计量：工资水平看中位数（免受极端值影响）、最受欢迎看众数、平均成绩看平均数。
  4. 含权重问题：按"平时:期中:期末"比例算综合成绩用加权平均数，权就是对应系数。

01

进位制的认识与探究

七上 综合与实践
本讲知识脉络
位值（位权）思想→ 十进制回顾→ 二进制（只有 0、1）→ 八进制 / 十六进制→ 进位制互化与简单运算

知识衔接：我们平时用的十进制，是"逢十进一"。理解"位权"（个位×1、十位×10…）之后，二进制（逢二进一）、八进制、十六进制就一通百通。它把有理数一章的乘方知识用到了实处，也是计算机科学的基础。

核心概念

  • 进位制：按"满几进一"计数，几就叫该进位制的基数（十进制基数 10，二进制基数 2）。
  • 位权：每一数位上的数字乘以其对应的权（如十进制的 10⁰、10¹、10²…）。
  • 二进制：只含数字 0、1，逢二进一。

重要公式与定理

①十进制展开：372 = 3×10² + 7×10¹ + 2×10⁰
②二进制转十进制：1101₂ = 1×2³+1×2²+0×2¹+1×2⁰ = 13
③十进制转二进制：不断除以 2 取余数，倒序排列
④任何进位制中：个位权 = 基数⁰，向左依次 ×基数

常见题型与解题方法

  1. 二进制 → 十进制：按位权展开求和（2 的幂）。
  2. 十进制 → 二进制：除 2 取余，余数倒序写出。
  3. 加减运算：二进制里"逢二进一"，如 1+1 = 10₂。
  4. 探究类问题：观察规律、从特殊到一般归纳（如 n 进制第 k 位的权是 nk−1）。

最短路径问题

八上 综合与实践
本讲知识脉络
两点之间线段最短→ 将军饮马（两定点 + 一直线）→ 作对称点转化→ 两点 / 三动点变式→ 实际应用（选址、送水、造桥）

知识衔接：核心模型是"将军饮马"：一位将军从营地 A 到河边饮马再到营地 B，找河边上的饮马点使总路程最短。做法是作 A 关于河（直线）的对称点 A′，连接 A′B，交点即最优点——本质是用轴对称把"折线"拉直成"线段最短"。它整合了七下的坐标、八上的轴对称。

核心概念

  • 将军饮马模型：在直线上求一点，使它到直线两侧两定点距离之和最短。
  • 转化思想：通过对称把"不在同一直线上的两点"转化为"同侧两点到直线的距离"，再用线段最短。
  • 变式：求周长最小、两点到直线加一段定长的桥（造桥选址）等。

重要公式与定理

①两点之间线段最短（基本依据）
②将军饮马作法：作其中一点关于直线的对称点 → 连另一点 → 交点即最优点
③最小路程 = 对称点与另一点的连线长（用坐标/勾股求）
④垂线段最短（点到直线类问题）

常见题型与解题方法

  1. 基本将军饮马：作对称点 → 连线 → 找交点 → 求最短路程。
  2. 在坐标系中求：用对称点坐标规律求 A′，再求 A′B 的长（水平竖直差构造直角，用勾股定理）。
  3. 求最小值类型：PA+PB 的最小值即 A′B 的长；△PAB 周长最小即再加 AB（定值）。
  4. 探究报告类：按"提出问题 → 猜想 → 说理证明 → 结论"格式写清楚步骤。
