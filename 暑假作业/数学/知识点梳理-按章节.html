第一章 有理数

1.1 正数和负数　1.2 有理数及其大小比较
核心知识点
  • 正数与负数：用带"+"（通常省略）和带"−"的数来表示具有相反意义的量，例如零上与零下温度、收入与支出、向东与向西。0 既不是正数也不是负数，它是正数与负数的分界，也表示"没有"或某一基准。
  • 有理数的分类：整数（正整数、0、负整数）和分数（正分数、负分数）统称有理数。按符号又可分为正有理数、0、负有理数。
  • 数轴：规定了原点、正方向和单位长度的直线叫数轴。任何一个有理数都可以用数轴上的一个点来表示。
  • 相反数：只有符号不同的两个数互为相反数，a 的相反数是 −a，0 的相反数是 0。在数轴上，互为相反数的两个点位于原点两侧且到原点距离相等。
  • 绝对值：数轴上表示数 a 的点到原点的距离，叫做数 a 的绝对值，记作 |a|。距离不可能为负，所以 |a| ≥ 0。
  • 有理数大小比较：正数都大于 0，负数都小于 0，正数大于负数；两个负数比较大小，绝对值大的反而小；数轴上右边的点表示的数总比左边的大。
重要公式 / 定理
绝对值：|a| = a（当 a ≥ 0 时）；|a| = −a（当 a < 0 时）
若 |a| = m（m ≥ 0），则 a = m 或 a = −m
互为相反数：a + (−a) = 0
典型例题
例 1在数轴上画出表示 −2.5、0、3、−1 的点，并把它们按从大到小排列。
解：先在数轴上从左到右依次标出这些点：−2.5 在 −3 和 −2 之间，−1 在 0 左侧一个单位，0 在原点，3 在原点右侧三个单位。
数轴上右边的数比左边的大，所以从大到小为：3 > 0 > −1 > −2.5。
例 2求下列各数的绝对值，并比较 −6 与 −7 的大小。
解：|5| = 5；|−3| = 3；|0| = 0。
比较 −6 与 −7：|−6| = 6，|−7| = 7。两个负数绝对值大的反而小，因为 7 > 6，所以 −7 < −6。

第二章 有理数的运算

2.1 有理数的加法　2.2 有理数的减法　2.3 有理数的乘法　2.4 有理数的除法　2.5 有理数的乘方　2.6 有理数的混合运算
核心知识点
  • 加法法则：同号两数相加，取相同的符号，并把绝对值相加；异号两数相加，取绝对值较大的加数的符号，并用较大的绝对值减去较小的绝对值；互为相反数的两个数相加得 0；一个数与 0 相加仍得这个数。
  • 减法法则：减去一个数，等于加上这个数的相反数，即 a − b = a + (−b)。由此减法统一为加法，再用加法法则计算。
  • 乘法法则：两数相乘，同号得正，异号得负，并把绝对值相乘；任何数与 0 相乘都得 0。几个不等于 0 的数相乘，负因数的个数为偶数时积为正，为奇数时积为负。
  • 除法法则：除以一个不等于 0 的数，等于乘以这个数的倒数，即 a ÷ b = a × (1/b)。注意：0 不能作除数。
  • 乘方：求 n 个相同因数的积的运算叫乘方，记作 aⁿ，a 叫底数，n 叫指数。负数的偶次幂是正数，负数的奇次幂是负数；0 的正整数次幂都是 0。
  • 运算律：加法的交换律 a+b=b+a、结合律 (a+b)+c=a+(b+c)；乘法的交换律 ab=ba、结合律 (ab)c=a(bc)、分配律 a(b+c)=ab+ac。灵活运用可简化计算。
  • 科学记数法与近似数：把一个大于 10 的数写成 a×10ⁿ 的形式（1 ≤ a < 10），叫科学记数法；近似数通过"四舍五入"取精确到某一位的数。
重要公式 / 定理
a − b = a + (−b)；a ÷ b = a × (1/b)（b ≠ 0）
(−a)ⁿ：n 为偶数时为正，n 为奇数时为负
a(b+c) = ab + ac（分配律）
典型例题
例 1计算：(1) −20 + (−14)；(2) −5 − (−9)；(3) (−3)²。
(1) 同号两数相加，取负号，绝对值相加：−20 + (−14) = −(20+14) = −34。
(2) 减法变加法：−5 − (−9) = −5 + 9。异号两数相加，取符号 9 的（正号），绝对值相减 9−5=4，得 4。
(3) (−3)² = (−3)×(−3)，负负得正：9。
例 2用简便方法计算：25 × 47 − 25 × 27。
解：逆用分配律，把相同的因数 25 提出来：
原式 = 25 × (47 − 27) = 25 × 20 = 500。

第三章 代数式

3.1 代数式　3.2 代数式求值
核心知识点
  • 用字母表示数：字母可以表示任意数，把具体数中反复出现的规律一般化，如长方形的面积 S = ab，这里 a、b 表示长和宽。
  • 代数式：用运算符号（+、−、×、÷、乘方等）把数和表示数的字母连接起来的式子叫代数式。单独的一个数或字母也是代数式。代数式中不含等号、不等号。
  • 代数式的书写规范：数字与字母相乘时省略乘号并把数字写在前面，如 3a 不写成 a×3 或 a3；除法写成分数形式，如 x÷2 写成 x/2；带分数与字母相乘时应化为假分数。
  • 代数式的值：用具体数值代替代数式里的字母，按照代数式中的运算关系计算得出的结果，叫做代数式的值。代入时要注意负数要加括号，如把 x = −2 代入 x²，写成 (−2)²。
  • 规律探究：由一组有规律的数或图形，先观察并猜出一般规律，再用含字母的代数式表示出来。
重要公式 / 定理
求值步骤：① 代入（注意加括号）；② 按运算顺序计算；③ 化简结果
典型例题
例 1用代数式表示：(1) x 与 5 的和；(2) a 的平方与 b 的差；(3) 温度由 t ℃ 下降 3 ℃ 后的温度。
解：(1) x + 5；(2) a² − b；(3) (t − 3) ℃。
例 2当 a = 3，b = −2 时，求代数式 a² − 2b 的值。
解：把 a = 3，b = −2 代入，注意负数 −2 加括号：
a² − 2b = 3² − 2×(−2) = 9 + 4 = 13。

第四章 整式的加减

4.1 整式的加减（合并同类项、去括号）
核心知识点
  • 单项式：由数与字母的积组成的代数式叫单项式，如 3a、−2x²y。单独一个数或一个字母也是单项式。单项式中的数字因数叫系数（如 −2x²y 的系数是 −2），所有字母的指数和叫次数。
  • 多项式：几个单项式的和叫多项式，其中每个单项式叫多项式的项，不含字母的项叫常数项。多项式里次数最高的项的次数就是多项式的次数。
  • 整式：单项式和多项式统称整式。判断一个式子是否为整式，看它是不是由数与字母的积或和组成（分母中不能含字母）。
  • 同类项：所含字母相同，并且相同字母的指数也分别相同的项叫同类项，如 3x²y 与 −5x²y。几个常数项也是同类项。
  • 合并同类项：把多项式中的同类项合并成一项，系数相加（字母和字母的指数不变）。
  • 去括号法则：括号前是"+"号，去括号后各项都不变号；括号前是"−"号，去括号后各项都要变号（正变负、负变正）。可以理解为：a + (b−c) = a + b − c；a − (b−c) = a − b + c。
重要公式 / 定理
合并同类项：ma + na = (m+n)a
去括号：a + (b−c) = a + b − c；a − (b−c) = a − b + c
典型例题
例 1合并同类项：3x² + 2x − 5x² − 4x + 1。
解：先找出同类项：3x² 与 −5x² 是同类项，2x 与 −4x 是同类项，1 是常数项。
原式 = (3−5)x² + (2−4)x + 1 = −2x² − 2x + 1。
例 2化简：2(x − 3) − 3(x + 1)。
解：先用分配律去括号（第二个括号前是"−3"，括号内每一项都要乘 −3，符号全变）：
原式 = 2x − 6 − 3x − 3 = (2x − 3x) + (−6 − 3) = −x − 9。

第五章 一元一次方程

5.1 方程　5.2 解一元一次方程　5.3 一元一次方程的应用
核心知识点
  • 方程与一元一次方程：含有未知数的等式叫方程。只含一个未知数（元），未知数的次数都是 1，且等号两边都是整式的方程叫一元一次方程，一般形式为 ax + b = 0（a ≠ 0）。
  • 方程的解与解方程：使方程左右两边相等的未知数的值叫方程的解；解方程就是求出这个解的过程。
  • 等式的性质：性质 1：等式两边加（或减）同一个数或式，结果仍相等；性质 2：等式两边乘同一个数，或除以同一个不为 0 的数，结果仍相等。解方程的每一步都依据这两条性质。
  • 移项：把方程一边的某一项变号后移到方程另一边，叫做移项。移项的本质是等式性质 1，是"加变减、减变加"的过程，例如 x + 3 = 5 移项得 x = 5 − 3。
  • 解方程的一般步骤：①去分母（两边同乘各分母的最小公倍数）；②去括号（用去括号法则）；③移项（变号）；④合并同类项；⑤系数化为 1（两边同除以未知数系数）。
  • 列方程解应用题：审题设未知数 → 找等量关系列方程 → 解方程 → 检验并作答。常见类型有：和差倍分问题、行程问题（路程=速度×时间）、工程问题、利润问题（售价−进价=利润）等。
重要公式 / 定理
等式性质 1：若 a = b，则 a ± c = b ± c
等式性质 2：若 a = b，则 ac = bc；若 a = b 且 c ≠ 0，则 a/c = b/c
路程 = 速度 × 时间；工作量 = 工作效率 × 时间；利润 = 售价 − 进价
典型例题
例 1解方程：3x + 5 = 2x − 7。
解：把含 x 的项移到左边，常数项移到右边（移项要变号）：
3x − 2x = −7 − 5，合并同类项得 x = −12。
检验：把 x = −12 代入，左边 3×(−12)+5 = −31，右边 2×(−12)−7 = −31，相等，所以解正确。
例 2一辆汽车从甲地开往乙地，每小时行 60 km，4 小时到达。返回时每小时行 80 km，返回需要几小时？
解：设返回需要 x 小时。去程和返程的路程相等，可列方程：
60 × 4 = 80x，即 240 = 80x，两边除以 80 得 x = 3。
答：返回需要 3 小时。检验：80×3 = 240，与去程路程相等，正确。

第六章 几何图形初步

6.1 几何图形　6.2 直线、射线、线段　6.3 角
核心知识点
  • 立体图形与平面图形：各部分不都在同一平面内的图形是立体图形（如长方体、圆柱、圆锥、球）；各部分都在同一平面内的图形是平面图形（如三角形、圆）。从不同的方向看立体图形得到三视图（正面、左面、上面）。
  • 点、线、面、体：几何图形由点、线、面、体组成，点是构成图形的基本元素。点动成线、线动成面、面动成体。
  • 直线、射线、线段：直线向两方无限延伸，无端点；射线向一方无限延伸，有一个端点；线段有两个端点。两点确定一条直线；两点之间线段最短（连接两点的所有线中，线段最短），两点的距离就是这条线段的长度。
  • 线段的中点：把一条线段分成两条相等线段的点叫线段的中点。若 C 是 AB 的中点，则 AC = CB = AB/2。
  • 角及其度量：有公共端点的两条射线组成的图形叫角，也可看作一条射线绕端点旋转形成的图形。角的度量单位是度、分、秒，1° = 60′，1′ = 60″。小于直角的角叫锐角，大于直角小于平角的角叫钝角。
  • 角的比较与平分：用量角器可比较角的大小；把一个角分成两个相等的角的射线叫角平分线。OC 平分 ∠AOB，则 ∠AOC = ∠COB = ∠AOB/2。
  • 余角与补角：如果两个角的和等于 90°，称这两个角互为余角；和等于 180°，互为补角。同角（或等角）的余角相等，同角（或等角）的补角相等。
重要公式 / 定理
线段中点：AC = CB = AB/2；角平分线：∠AOC = ∠COB = ∠AOB/2
1° = 60′，1′ = 60″
同角（等角）的余角相等；同角（等角）的补角相等
典型例题
例 1已知 C 是线段 AB 的中点，AB = 8 cm，求 AC 的长。
解：因为 C 是 AB 的中点，所以 AC = AB/2 = 8 ÷ 2 = 4 cm。
例 2一个角是 35°，求它的余角和补角的度数。
解：余角 = 90° − 35° = 55°；补角 = 180° − 35° = 145°。

第七章 相交线与平行线

7.1 相交线　7.2 平行线及其判定　7.3 平行线的性质　7.4 平移　7.5 定义、命题、定理
核心知识点
  • 邻补角与对顶角：两条直线相交，有公共顶点且有一条公共边的两个角互为邻补角（和等于 180°）；有公共顶点但两边分别互为反向延长线的两个角互为对顶角。对顶角相等。
  • 垂线：两条直线相交成直角时，叫互相垂直，交点叫垂足。过一点有且只有一条直线与已知直线垂直；垂线段最短（从直线外一点到直线的垂线段的长度叫点到直线的距离）。
  • 三线八角：两条直线被第三条直线所截形成八个角：同位角（位置相同，形如"F"）、内错角（交错且在内侧，形如"Z"）、同旁内角（同旁且在内侧，形如"U"）。
  • 平行线的判定：①同位角相等，两直线平行；②内错角相等，两直线平行；③同旁内角互补，两直线平行；④平行于同一条直线的两直线平行；⑤同一平面内，垂直于同一条直线的两直线平行。
  • 平行线的性质：两条平行线被第三条直线所截，①同位角相等；②内错角相等；③同旁内角互补。注意判定与性质正好"反过来"，要能根据已知条件判断用哪一边。
  • 平移：把图形沿某一方向移动一定距离，图形的形状和大小都不变，对应点所连线段平行且相等。
  • 命题、定理、证明：判断一件事情的语句叫命题，由题设（已知）和结论组成；经过推理证实的真命题叫定理；证明就是从题设出发，通过推理得出结论的过程。
重要公式 / 定理
对顶角相等；邻补角互补（和为 180°）
判定：同位角相等 ⇒ 平行；内错角相等 ⇒ 平行；同旁内角互补 ⇒ 平行
性质：平行 ⇒ 同位角相等；平行 ⇒ 内错角相等；平行 ⇒ 同旁内角互补
典型例题
例 1如图，a ∥ b，∠1 = 70°，求 ∠2、∠3 的度数（∠2 与 ∠1 是同位角，∠3 与 ∠1 是对顶角）。
解：因为 a ∥ b，同位角相等，所以 ∠2 = ∠1 = 70°。
因为对顶角相等，所以 ∠3 = ∠1 = 70°。
例 2如图，∠1 = 50°，∠2 = 50°，判断直线 a 与 b 是否平行，并说明理由。
解：因为 ∠1 = ∠2 = 50°，即同位角相等，根据"同位角相等，两直线平行"，所以 a ∥ b。

第八章 实数

8.1 平方根　8.2 立方根　8.3 实数及运算
核心知识点
  • 算术平方根：一般地，如果一个正数 x 的平方等于 a（x² = a，a ≥ 0），那么正数 x 叫做 a 的算术平方根，记作 √a。规定 0 的算术平方根是 0。被开方数 a 必须是非负数。
  • 平方根：如果一个数 x 的平方等于 a，那么 x 叫做 a 的平方根。正数有两个平方根，互为相反数（记作 ±√a）；0 的平方根是 0；负数没有平方根。
  • 立方根：如果一个数 x 的立方等于 a，那么 x 叫做 a 的立方根，记作 ∛a。正数立方根是正数，负数立方根是负数，0 的立方根是 0。任意实数都有唯一的立方根。
  • 无理数：无限不循环小数叫无理数，如 √2、√3、π、0.1010010001…。有理数和无理数统称实数。
  • 实数的分类：实数可分为有理数和无理数两大类；也可分为正实数、0、负实数。数轴上的点与实数一一对应。
  • 实数的运算与比较：实数的运算顺序和有理数相同（先乘方开方，再乘除，后加减，有括号先算括号）；比较两个正实数可比较它们的平方。
重要公式 / 定理
算术平方根：(√a)² = a（a ≥ 0）；√a² = |a|
平方根：±√a 满足 (±√a)² = a；立方根：∛a 满足 (∛a)³ = a，∛(−a) = −∛a
典型例题
例 1求下列各数的平方根和算术平方根：(1) 16；(2) 0.09。
(1) 因为 (±4)² = 16，所以 16 的平方根是 ±4，算术平方根是 4。
(2) 因为 (±0.3)² = 0.09，所以 0.09 的平方根是 ±0.3，算术平方根是 0.3。
例 2求 √49 和 ∛(−27) 的值。
解：因为 7² = 49，所以 √49 = 7；因为 (−3)³ = −27，所以 ∛(−27) = −3。

第九章 平面直角坐标系

9.1 平面直角坐标系　9.2 坐标方法的简单应用
核心知识点
  • 平面直角坐标系：在平面内画两条互相垂直、原点重合的数轴，水平的叫 x 轴（横轴），竖直的叫 y 轴（纵轴），交点叫原点，合称坐标轴。有了坐标系，平面内每一个点都可用一对有序数对 (x, y) 表示，这对数叫点的坐标，其中 x 是横坐标、y 是纵坐标。
  • 象限：两条坐标轴把平面分成四个象限（右上为第一象限，按逆时针为第二、三、四象限）。第一象限坐标（+，+），第二象限（−，+），第三象限（−，−），第四象限（+，−）。坐标轴上的点不属于任何象限。
  • 坐标轴上及特殊位置的点的特点：x 轴上的点纵坐标为 0（如 (a,0)）；y 轴上的点横坐标为 0（如 (0,b)）；原点 (0,0)。角平分线上的点：一、三象限角平分线上 x = y，二、四象限角平分线上 x = −y。
  • 用坐标表示地理位置：建立坐标系、确定单位长度和原点，用坐标表示各点的位置。
  • 坐标系中的平移：点 (x, y) 向右平移 a 个单位得 (x+a, y)，向左得 (x−a, y)；向上平移 b 个单位得 (x, y+b)，向下得 (x, y−b)。口诀：右加左减（横坐标）、上加下减（纵坐标）。图形的平移就是所有点按同样的方式平移。
重要公式 / 定理
左右平移：横坐标变（右加左减），纵坐标不变
上下平移：纵坐标变（上加下减），横坐标不变
典型例题
例 1写出点 (3, −2) 所在的象限。
解：横坐标 3 > 0，纵坐标 −2 < 0，符号为（+，−），所以点 (3, −2) 在第 四象限。
例 2把点 A(2, 3) 先向右平移 4 个单位，再向下平移 2 个单位，求平移后点 A′ 的坐标。
解：向右平移 4 个单位，横坐标加 4：2 + 4 = 6，得 (6, 3)；
再向下平移 2 个单位，纵坐标减 2：3 − 2 = 1，得 A′ 坐标为 (6, 1)。

第十章 二元一次方程组

10.1 二元一次方程组　10.2 消元法解二元一次方程组　10.3 方程组的应用
核心知识点
  • 二元一次方程：含有两个未知数，并且含未知数的项的次数都是 1 的整式方程叫二元一次方程，如 x + y = 10。它的解有无数个（二元一次方程的解是一对数值）。
  • 二元一次方程组：两个二元一次方程合在一起组成方程组，如 {x + y = 10, x − y = 4}。两个方程的公共解叫方程组的解，只有一个。
  • 代入消元法：把一个方程变形为"用一个未知数表示另一个未知数"（如由 x + y = 10 得 x = 10 − y），再代入另一个方程，把二元方程组化为一元一次方程求解。这种方法叫代入消元法。
  • 加减消元法：把两个方程左右两边分别相加或相减，消去一个未知数（当两个方程中某个未知数的系数相同或互为相反数时最方便），再解一元一次方程。
  • 列方程组解应用题：和列一元一次方程类似，但设两个未知数，找到两个等量关系列出两个方程。常见问题：鸡兔同笼、和差问题、行程相遇追及问题、配套问题等。
重要公式 / 定理
消元思想：把"二元"转化为"一元"，再解一元一次方程
典型例题
例 1用代入法解方程组：{x + y = 10　①；x − y = 4　②。
解：由 ① 得 x = 10 − y（用一个未知数表示另一个）③。
把 ③ 代入 ②：(10 − y) − y = 4，即 10 − 2y = 4，移项得 −2y = −6，所以 y = 3。
把 y = 3 代入 ③，x = 10 − 3 = 7。
所以方程组的解为 x = 7，y = 3。
例 2笼中共有鸡和兔 20 个头，54 只脚，问鸡、兔各几只？
解：设鸡有 x 只，兔有 y 只。由头数得 x + y = 20；由脚数得 2x + 4y = 54。
由 x + y = 20 得 x = 20 − y，代入 2x + 4y = 54：2(20 − y) + 4y = 54，
即 40 + 2y = 54，y = 7，x = 20 − 7 = 13。
答：鸡 13 只，兔 7 只。

第十一章 不等式与不等式组

11.1 不等式及其解集　11.2 一元一次不等式　11.3 一元一次不等式组
核心知识点
  • 不等式与不等式的解集：用">、<、≥、≤"表示大小关系的式子叫不等式。不等式的解有无数个，全体解组成的集合叫解集，解集可以在数轴上表示（空心圆圈表示不取该点，实心圆点表示取该点）。
  • 不等式的性质：性质 1：不等式两边加（或减）同一个数，不等号方向不变；性质 2：两边乘（或除以）同一个正数，方向不变；性质 3：两边乘（或除以）同一个负数，不等号方向改变（这是与等式最大的不同，最容易出错）。
  • 解一元一次不等式：步骤与解方程类似（去分母、去括号、移项、合并、系数化为 1），但系数化为 1 时若除以负数，不等号要改变方向。
  • 一元一次不等式组：几个一元一次不等式合在一起组成不等式组，各不等式解集的公共部分就是不等式组的解集。
  • 求不等式组解集的口诀：同大取大（都取大的方向，取较大的边界）；同小取小；大小小大取中间（大于小数、小于大数，解集在两数之间）；大大小小无解（大于大数、小于小数，无解）。
  • 不等式的应用：列不等式解应用题，抓住"至少""不超过""至多"等关键词确定不等号，如"至少 x 件"表示 x ≥ 某数。
重要公式 / 定理
若 a > b，则 a + c > b + c
若 a > b，c > 0，则 ac > bc；若 a > b，c < 0，则 ac < bc（方向改变！）
不等式组解集：同大取大、同小取小、大小小大取中间、大大小小无解
典型例题
例 1解不等式：−2x < 6，并把解集在数轴上表示。
解：两边除以 −2（负数，不等式方向要改变）：
−2x < 6 ⇒ x > 6 ÷ (−2) = −3，即解集为 x > −3。
数轴表示：在数轴 −3 处画空心圆圈，向右边画射线。
例 2求不等式组 {x > 2　①；x ≤ 5　②} 的解集。
解：①表示大于 2，②表示小于等于 5，属于"大小小大取中间"情形，
所以解集为 2 < x ≤ 5。在数轴上：2 处画空心圆圈，5 处画实心圆点，中间部分涂黑。

第十二章 数据的收集、整理与描述

12.1 统计调查　12.2 直方图
核心知识点
  • 全面调查与抽样调查：对全体对象进行调查叫全面调查（普查），适合对象数量少或需要精确结果的场合（如人口普查）；只抽取一部分对象进行调查叫抽样调查，适合对象太多或调查有破坏性的场合（如检查一批灯泡寿命）。
  • 总体、个体、样本、样本容量：调查对象的全体叫总体；组成总体的每一个对象叫个体；从总体中抽取的一部分个体组成样本；样本中个体的数目叫样本容量。
  • 频数与频率：每个对象（或各组数据）出现的次数叫频数；频数占总数据个数的比例叫频率，频率 = 频数 ÷ 总数，各组频率之和等于 1。
  • 统计图的选择：条形图能清楚地表示每组数据的数量（多少）；扇形图能清楚地表示各部分占总体的百分比；折线图能清楚地反映数据的变化趋势。
  • 直方图：用于表示数据分布情况，先把数据分组（确定组距和组数），再统计每组频数，画成以组距为底边、以频数为高的直方图。各组频数之和等于数据总数。
重要公式 / 定理
频率 = 频数 ÷ 总数；各组频率之和 = 1；各组频数之和 = 总数
组数 = 最大值−最小值 / 组距（取整数，一般用"进一法"）
典型例题
例 1要了解全校 2000 名学生的视力情况，从各年级随机抽取了 200 名学生进行调查。指出这里的总体、个体、样本和样本容量。
解：总体是全校 2000 名学生的视力；个体是每名学生的视力；样本是被抽取的 200 名学生的视力；样本容量是 200。
例 2某班 50 名同学中，喜欢数学的有 15 人，求喜欢数学的人数占全班人数的百分比，以及在扇形图中对应的圆心角度数。
解：百分比 = 15 ÷ 50 = 30%。
扇形圆心角 = 360° × 30% = 108°。

第十三章 三角形

13.1 三角形的边角关系　13.2 三角形中的特殊线段　13.3 多边形及其内角和
核心知识点
  • 三角形的概念与分类：由不在同一直线上的三条线段首尾顺次相接组成的图形叫三角形。按边分为等边三角形、等腰三角形（含等边）和一般三角形；按角分为锐角三角形、直角三角形和钝角三角形。
  • 三边关系：三角形任意两边之和大于第三边，任意两边之差小于第三边。判断能否组成三角形，只需看"较短两边之和是否大于最长边"。
  • 三角形的高、中线、角平分线：高：从顶点向对边作垂线，顶点到垂足的线段；中线：连接顶点与对边中点的线段，三条中线交于一点叫重心；角平分线：平分角的线段，交于内心。中线把三角形分成两个面积相等的三角形。
  • 三角形的稳定性：三角形三边确定后形状不会改变，具有稳定性，广泛用于建筑和桥梁结构。
  • 内角和定理：三角形三个内角的和等于 180°。直角三角形的两个锐角互余。
  • 外角：三角形一边与另一边的延长线组成的角叫外角。三角形的一个外角等于与它不相邻的两个内角之和；外角大于任何一个与它不相邻的内角。三角形外角和为 360°。
  • 多边形内角与外角和：n 边形内角和 = (n − 2) × 180°；任意多边形的外角和都等于 360°。多边形的对角线总条数 = n(n−3)/2。
重要公式 / 定理
任意两边之和大于第三边；任意两边之差小于第三边
三角形内角和 = 180°；三角形外角和 = 360°
n 边形内角和 = (n − 2) × 180°；n 边形对角线条数 = n(n−3)/2
典型例题
例 1已知三角形两边长分别为 3 和 8，求第三边长的取值范围。
解：设第三边为 x。根据三边关系，两边之差 < 第三边 < 两边之和：
8 − 3 < x < 8 + 3，即 5 < x < 11。
例 2求十边形的内角和。
解：十边形 n = 10，内角和 = (10 − 2) × 180° = 8 × 180° = 1440°。

第十四章 全等三角形

14.1 全等三角形　14.2 三角形全等的判定　14.3 角的平分线
核心知识点
  • 全等形与全等三角形：能够完全重合的两个图形叫全等形；完全重合的两个三角形叫全等三角形，用"≌"表示。互相重合的顶点、边、角分别叫对应顶点、对应边、对应角。
  • 全等三角形的性质：对应边相等，对应角相等，周长相等，面积相等。
  • SSS：三边分别相等的两个三角形全等（边边边）。只要三条边确定，三角形形状就唯一确定。
  • SAS：两边和它们的夹角分别相等的两个三角形全等（边角边）。注意必须是"夹角"，不是任意角。
  • ASA：两角和它们的夹边分别相等的两个三角形全等（角边角）。
  • AAS：两角分别相等且其中一组等角的对边也相等的两个三角形全等（角角边）。由三角形内角和为 180° 可知 AAS 与 ASA 等价。
  • HL（直角三角形专用）：斜边和一条直角边分别相等的两个直角三角形全等。
  • 角平分线的性质与判定：角平分线上的点到角两边的距离相等；反过来，角的内部到角两边距离相等的点在角平分线上。
重要公式 / 定理
全等判定口诀：SSS、SAS（夹角）、ASA（夹边）、AAS、HL（直角三角形）
角平分线性质：点 P 在 ∠AOB 平分线上 ⇒ P 到 OA、OB 距离相等
典型例题
例 1如图，已知 AB = DE，AC = DF，BC = EF，说明 △ABC ≌ △DEF 的理由。
解：三边分别相等，根据 SSS，可得 △ABC ≌ △DEF。
由全等对应边相等，还可以推出 AB = DE、AC = DF、BC = EF 等结论。
例 2如图，∠AOB 的平分线为 OC，点 P 在 OC 上，PM ⊥ OA 于 M，PM = 5 cm，求点 P 到 OB 的距离。
解：根据"角平分线上的点到角两边的距离相等"，点 P 到 OB 的距离等于点 P 到 OA 的距离，
所以 P 到 OB 的距离 = 5 cm。

第十五章 轴对称

15.1 图形的轴对称　15.2 画轴对称图形　15.3 等腰三角形
核心知识点
  • 轴对称与轴对称图形：把一个图形沿某条直线折叠，如果它能与另一个图形重合，则两个图形关于这条直线轴对称（轴对称）；如果一个图形沿一条直线折叠后直线两旁的部分能互相重合，这个图形叫轴对称图形（如等腰三角形、圆）。两者的共同点是都有对称轴。
  • 轴对称的性质：关于某条直线对称的两个图形全等；对称轴是任何一对对应点所连线段的垂直平分线；对应点连线被对称轴垂直平分。
  • 线段垂直平分线：垂直于一条线段并且平分这条线段的直线叫垂直平分线。性质：垂直平分线上的点到线段两端点的距离相等；判定：到线段两端点距离相等的点在这条线段的垂直平分线上。
  • 关于坐标轴对称的点的坐标：点 (x, y) 关于 x 轴对称的点的坐标是 (x, −y)（横坐标不变，纵坐标变号）；关于 y 轴对称的点的坐标是 (−x, y)（纵坐标不变，横坐标变号）。
  • 等腰三角形的性质：两腰相等；两底角相等（等边对等角）；三线合一——顶角平分线、底边上的中线、底边上的高互相重合；是轴对称图形，对称轴为底边上的中线所在直线。
  • 等腰三角形的判定：如果一个三角形有两个角相等，那么这两个角所对的边也相等（等角对等边）。
  • 等边三角形：三条边都相等，三个内角都等于 60°。有一个角是 60° 的等腰三角形是等边三角形；三边都相等的三角形是等边三角形。每个内角的平分线、中线、高也重合。
重要公式 / 定理
垂直平分线性质：点 P 在 AB 的垂直平分线上 ⇒ PA = PB
关于 x 轴对称：(x, y) → (x, −y)；关于 y 轴对称：(x, y) → (−x, y)
等腰三角形：等边对等角；等角对等边；三线合一
典型例题
例 1等腰三角形的一个顶角是 80°，求它的底角度数。
解：等腰三角形两底角相等，设每个底角为 x°。由内角和定理：
80° + x + x = 180°，2x = 100°，每个底角 = 50°。
例 2点 A(3, 5) 关于 x 轴和 y 轴对称的点分别是什么？
解：关于 x 轴对称，横坐标不变、纵坐标变号，得 (3, −5)；
关于 y 轴对称，纵坐标不变、横坐标变号，得 (−3, 5)。

第十六章 整式的乘法

16.1 幂的运算　16.2 整式的乘法　16.3 乘法公式　16.4 同底数幂的除法
核心知识点
  • 同底数幂的乘法：同底数幂相乘，底数不变，指数相加，即 aᵐ · aⁿ = aᵐ⁺ⁿ。注意底数相同才能直接相加。
  • 幂的乘方：底数不变，指数相乘，即 (aᵐ)ⁿ = aᵐⁿ。
  • 积的乘方：把积中每个因式分别乘方，再把所得的幂相乘，即 (ab)ⁿ = aⁿbⁿ。
  • 单项式乘法：系数与系数相乘，同底数幂相乘，对于只在一个单项式里含有的字母，连同它的指数作为积的一个因式。
  • 多项式乘法：用多项式的每一项去乘另一个多项式的每一项，再把所得的积相加，即 (a+b)(c+d) = ac + ad + bc + bd（先乘开再合并同类项）。
  • 平方差公式：(a + b)(a − b) = a² − b²，两个数的和与这两个数的差的积等于这两个数的平方差。
  • 完全平方公式：(a + b)² = a² + 2ab + b²；(a − b)² = a² − 2ab + b²。口诀：首平方，尾平方，首尾乘积的两倍放中央（符号看中间）。
  • 同底数幂的除法：同底数幂相除，底数不变，指数相减，即 aᵐ ÷ aⁿ = aᵐ⁻ⁿ（a ≠ 0）。任何不等于 0 的数的 0 次幂等于 1，即 a⁰ = 1（a ≠ 0）。
重要公式 / 定理
aᵐ · aⁿ = aᵐ⁺ⁿ；(aᵐ)ⁿ = aᵐⁿ；(ab)ⁿ = aⁿbⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ（a ≠ 0）；a⁰ = 1（a ≠ 0）
(a+b)(a−b) = a² − b²
(a±b)² = a² ± 2ab + b²
典型例题
例 1计算：(1) x² · x⁵；(2) (a³)⁴；(3) (2a²b)³。
(1) 同底数幂相乘，指数相加：x² · x⁵ = x²⁺⁵ = x⁷。
(2) 幂的乘方，指数相乘：(a³)⁴ = a³ˣ⁴ = a¹²。
(3) 积的乘方：(2a²b)³ = 2³ · a⁶ · b³ = 8a⁶b³。
例 2计算：(1) (3x + 2)(3x − 2)；(2) (x + 5)²。
(1) 平方差公式：把 3x 看作 a，2 看作 b：(3x + 2)(3x − 2) = (3x)² − 2² = 9x² − 4。
(2) 完全平方公式：(x + 5)² = x² + 2·x·5 + 5² = x² + 10x + 25。

第十七章 因式分解

17.1 因式分解　17.2 提公因式法　17.3 公式法
核心知识点
  • 因式分解的概念：把一个多项式化成几个整式的积的形式，叫因式分解，如 x² − 9 = (x + 3)(x − 3)。它与整式乘法是互逆的过程（乘法是"展开"，因式分解是"分解"）。
  • 提公因式法：找多项式各项的公因式（各项系数的最大公因数 × 各项都含有的相同字母的最低次幂），把它提出来，如 ma + mb + mc = m(a + b + c)。注意：提完公因式后要看剩余部分是否正确。
  • 公式法——平方差：a² − b² = (a + b)(a − b)。能用平方差公式的条件：两项、符号相反、都能写成平方的形式。
  • 公式法——完全平方：a² ± 2ab + b² = (a ± b)²。能用完全平方公式的条件：三项、首尾两项是平方且符号相同、中间一项是首尾乘积的 2 倍（可正可负）。
  • 十字相乘法（拓展）：对二次三项式 x² + (p+q)x + pq = (x + p)(x + q)，找两个数，它们的和等于一次项系数、积等于常数项。
  • 因式分解的一般步骤：一提（提公因式）→ 二套（套公式）→ 三检查（每个因式都不能再分解，分解要彻底）。
重要公式 / 定理
ma + mb + mc = m(a + b + c)
a² − b² = (a + b)(a − b)
a² ± 2ab + b² = (a ± b)²
典型例题
例 1因式分解：(1) 6a²b − 9ab²；(2) x² − 16。
(1) 公因式为 3ab：6a²b − 9ab² = 3ab(2a − 3b)。检验：3ab·2a = 6a²b，3ab·(−3b) = −9ab²，正确。
(2) 平方差公式：x² − 16 = x² − 4² = (x + 4)(x − 4)。
例 2因式分解：x² + 6x + 9。
解：首项 x² 是平方，末项 9 = 3²，中间项 6x = 2·x·3，满足完全平方公式：
x² + 6x + 9 = (x + 3)²。

第十八章 分式

18.1 分式的概念与基本性质　18.2 分式的运算　18.3 分式方程
核心知识点
  • 分式的概念：如果 A、B 表示两个整式，并且 B 中含有字母，那么式子 A/B 叫分式。分式的值是整式还是分式，关键看分母中是否含有字母。
  • 分式有意义的条件：分母不能为 0，即 B ≠ 0 时分式有意义；分母为 0 时无意义；当分子为 0 且分母不为 0 时，分式的值为 0。
  • 分式的基本性质：分式的分子、分母同乘（或除以）同一个不等于 0 的整式，分式的值不变，即 A/B = (A×C)/(B×C)（C ≠ 0）。这是约分和通分的依据。
  • 约分与最简分式：把分式中分子分母的公因式约去叫约分；分子和分母没有公因式的分式叫最简分式。
  • 分式的运算：同分母分式相加减，分母不变分子相加减；异分母先通分再加减。分式乘分式，分子相乘作分子、分母相乘作分母；分式除以分式，等于乘以除式的倒数。乘方时分子分母分别乘方。最后结果要约成最简分式。
  • 分式方程：分母中含有未知数的方程叫分式方程。解法：两边同乘最简公分母，化为整式方程求解。
  • 增根与检验：化为整式方程时两边乘了含未知数的式子，可能产生使分母为 0 的根（增根），所以解完必须代入最简公分母检验：若为 0，则舍去，该方程无解；不为 0，才是原方程的根。
重要公式 / 定理
A/B 有意义 ⟺ B ≠ 0；A/B = 0 ⟺ A = 0 且 B ≠ 0
A/B = (A×C)/(B×C)，A/B = (A÷C)/(B÷C)（C ≠ 0）
分式方程必须验根：代入最简公分母，为 0 是增根要舍去
典型例题
例 1当 x 为何值时，分式 3/(x − 2) 有意义？当 x 为何值时，分式的值为 0？
解：分母不为 0 时分式有意义，即 x − 2 ≠ 0，所以 x ≠ 2 时有意义。
本题分子 3 恒不为 0，所以不存在使分式值为 0 的 x。
例 2解分式方程：1/x + 1/(x+2) = 1。
解：最简公分母为 x(x+2)，两边同乘：
(x + 2) + x = x(x + 2)，整理得 x² + 2x − 2x − 2 = 0，即 x² = 2，x = ±√2。
检验：把 x = ±√2 代入最简公分母 x(x+2)，均不为 0，所以原方程的解为 x = √2 或 x = −√2。

第十九章 二次根式

19.1 二次根式及其性质　19.2 二次根式的乘法与除法　19.3 二次根式的加减
核心知识点
  • 二次根式的概念：形如 √a（a ≥ 0）的式子叫二次根式，其中 a 是被开方数。被开方数必须是非负数（a ≥ 0），这是二次根式有意义的条件。
  • 二次根式的性质：①(√a)² = a（a ≥ 0）；②√a² = |a|，即当 a ≥ 0 时 √a² = a，当 a < 0 时 √a² = −a。性质②是关键，化简时一定要先看 a 的符号。
  • 二次根式的乘法：√a · √b = √(ab)（a ≥ 0，b ≥ 0）。反过来可把 √(ab) 拆成 √a · √b 用于化简。
  • 二次根式的除法：√a ÷ √b = √(a/b)（a ≥ 0，b > 0）。分母中不含根号的化简叫分母有理化，如 1/√2 = √2/2。
  • 最简二次根式：满足两个条件：被开方数不含分母；被开方数中不含能开得尽方的因数（因式）。如 √12 化简为 2√3。
  • 二次根式的加减：先把各二次根式化成最简二次根式，再把被开方数相同的二次根式合并（系数相加减，根号部分不变），类似合并同类项。
重要公式 / 定理
有意义条件：√a 中 a ≥ 0
(√a)² = a（a ≥ 0）；√a² = |a|
√a · √b = √(ab)；√a ÷ √b = √(a/b)
典型例题
例 1化简：(1) √12；(2) √50；(3) √(−3)²。
(1) √12 = √(4×3) = √4 × √3 = 2√3。
(2) √50 = √(25×2) = √25 × √2 = 5√2。
(3) 用性质 √a² = |a|：√(−3)² = |−3| = 3。
例 2计算：√8 + √18。
解：先化为最简二次根式：√8 = 2√2，√18 = 3√2，
再合并（系数相加）：2√2 + 3√2 = 5√2。

第二十章 勾股定理

20.1 勾股定理　20.2 勾股定理的逆定理　20.3 勾股定理的应用
核心知识点
  • 勾股定理：如果直角三角形的两条直角边分别为 a、b，斜边为 c，那么 a² + b² = c²，即两直角边的平方和等于斜边的平方。这是直角三角形最重要的性质。
  • 勾股定理的应用：已知直角三角形的两边，可求第三边：c = √(a²+b²)，a = √(c²−b²)。常用于求线段长度、最短路径（把立体图形展开成平面再求直线距离）等问题。
  • 勾股定理的逆定理：如果三角形的三边长 a、b、c 满足 a² + b² = c²，那么这个三角形是直角三角形（c 为斜边）。它是判断直角三角形（尤其知道三边长度时）的有力工具。
  • 勾股数：满足 a² + b² = c² 的三个正整数叫勾股数，如 3、4、5；5、12、13；6、8、10；8、15、17；7、24、25。勾股数的整数倍仍是勾股数。
  • 两点间距离（网格中）：在坐标系或网格中，两点间的距离可用勾股定理计算：横坐标差、纵坐标差分别为两直角边，斜边即距离。
重要公式 / 定理
直角三角形：a² + b² = c²（c 为斜边）
逆定理：若 a² + b² = c²，则三角形为直角三角形
常用勾股数：3-4-5、5-12-13、6-8-10、7-24-25、8-15-17
典型例题
例 1直角三角形两直角边分别为 3 和 4，求斜边长。
解：由勾股定理 c² = 3² + 4² = 9 + 16 = 25，所以 c = √25 = 5。
（这也说明 3、4、5 是一组勾股数。）
例 2判断三边长为 6、8、10 的三角形是不是直角三角形。
解：最长边为 10。检验：6² + 8² = 36 + 64 = 100 = 10²，满足勾股定理的逆定理，
所以这个三角形是 直角三角形，10 是斜边。

第二十一章 平行四边形

21.1 平行四边形的性质　21.2 平行四边形的判定　21.3 矩形、菱形、正方形　21.4 三角形的中位线
核心知识点
  • 平行四边形的定义与性质：两组对边分别平行的四边形叫平行四边形。性质：对边相等且平行；对角相等；对角线互相平分；它是中心对称图形，对称中心是两条对角线的交点。
  • 平行四边形的判定：①两组对边分别平行；②两组对边分别相等；③一组对边平行且相等；④两组对角分别相等；⑤对角线互相平分。满足任一条即可判定为平行四边形。
  • 矩形：有一个角是直角的平行四边形叫矩形。性质：四个角都是直角；对角线相等。判定：有三个角是直角的四边形；有一个角是直角的平行四边形；对角线相等的平行四边形。
  • 菱形：有一组邻边相等的平行四边形叫菱形。性质：四条边都相等；对角线互相垂直且每条对角线平分一组对角。面积 = 对角线乘积的一半。判定：四条边都相等的四边形；有一组邻边相等的平行四边形；对角线互相垂直的平行四边形。
  • 正方形：四条边都相等且四个角都是直角的四边形叫正方形，它既是矩形又是菱形，具有它们所有的性质。对角线相等、互相垂直且平分。
  • 三角形的中位线：连接三角形两边中点的线段叫中位线。定理：三角形的中位线平行于第三边，且等于第三边的一半。
重要公式 / 定理
平行四边形：对边平行且相等；对角相等；对角线互相平分
矩形对角线相等；菱形对角线互相垂直；正方形兼具二者
中位线定理：DE 是 △ABC 中位线 ⇒ DE ∥ BC 且 DE = BC/2
典型例题
例 1平行四边形 ABCD 的周长为 30，一边 AB = 8，求相邻边 BC 的长。
解：平行四边形对边相等，AB = CD = 8，BC = AD。周长 = 2(AB + BC) = 30，
所以 AB + BC = 15，BC = 15 − 8 = 7。
例 2菱形两条对角线长分别为 6 和 8，求它的面积和边长。
解：面积 = 对角线乘积的一半 = 6 × 8 ÷ 2 = 24。
菱形对角线互相垂直平分，边长 = √(3² + 4²) = √25 = 5。

第二十二章 一次函数

22.1 变量与函数　22.2 一次函数　22.3 一次函数的图象与性质　22.4 待定系数法　22.5 一次函数与方程、不等式
核心知识点
  • 变量与常量：在一个变化过程中，数值发生变化的量叫变量，数值始终不变的量叫常量。例如汽车行驶中，时间、路程是变量，速度（匀速时）是常量。
  • 函数的概念：一般地，在一个变化过程中有两个变量 x 和 y，如果对于 x 的每一个确定的值，y 都有唯一确定的值与之对应，那么 y 是 x 的函数，x 叫自变量，y 叫因变量。
  • 一次函数与正比例函数：形如 y = kx + b（k、b 是常数，k ≠ 0）的函数叫一次函数；当 b = 0 时 y = kx 叫正比例函数，它是特殊的一次函数。注意 k ≠ 0 才是一次函数。
  • 一次函数的图象：一次函数 y = kx + b 的图象是一条直线，可由两点确定（常取与 x 轴、y 轴的交点）。正比例函数 y = kx 的图象是经过原点的直线。
  • k、b 的意义：k 决定直线的走向（k > 0 时 y 随 x 增大而增大，直线从左下到右上；k < 0 时 y 随 x 增大而减小，直线从左上到右下），|k| 越大直线越陡；b 是直线与 y 轴交点的纵坐标（y 轴截距），b > 0 交于 y 轴正半轴，b < 0 交于负半轴。
  • 待定系数法：先设一次函数为 y = kx + b，把图象经过的点的坐标代入，得到关于 k、b 的方程组，解出 k、b 从而确定函数解析式。步骤：设 → 代 → 解 → 写。
  • 一次函数与方程、不等式的关系：y = kx + b 的图象与 x 轴交点的横坐标就是方程 kx + b = 0 的解；图象在 x 轴上方（或下方）的部分对应的 x 范围就是不等式 kx + b > 0（或 < 0）的解集。
重要公式 / 定理
一次函数：y = kx + b（k ≠ 0）；正比例函数：y = kx（k ≠ 0）
k > 0 递增、过一三象限；k < 0 递减、过二四象限
kx + b = 0 的解 = 图象与 x 轴交点的横坐标
典型例题
例 1已知一次函数的图象经过点 (0, 3) 和 (2, 7)，求这个一次函数的解析式。
解：设 y = kx + b。把 (0, 3) 代入得 b = 3；把 (2, 7) 代入得 2k + 3 = 7，
解得 k = 2。所以解析式为 y = 2x + 3。
例 2一次函数 y = −2x + 4 与 x 轴、y 轴的交点坐标分别是什么？
解：与 y 轴交点：令 x = 0，得 y = 4，交点为 (0, 4)；
与 x 轴交点：令 y = 0，得 −2x + 4 = 0，x = 2，交点为 (2, 0)。

第二十三章 数据的分析

23.1 平均数　23.2 中位数与众数　23.3 方差　23.4 四分位数
核心知识点
  • 算术平均数：n 个数 x₁、x₂、…、xₙ 的和除以 n，即 x̄ = (x₁ + x₂ + … + xₙ)/n。平均数反映数据的平均水平，但受极端值影响大。
  • 加权平均数：当数据的重要程度不同时，用加权平均数：x̄ = (x₁w₁ + x₂w₂ + … + xₙwₙ)/(w₁ + w₂ + … + wₙ)，其中 w 叫权，权越大该项对平均数影响越大。比如平时、期中、期末按 3:3:4 加权算总评。
  • 中位数：把一组数据按从小到大排列后，位于最中间位置的数叫中位数。若数据个数为奇数，中位数是正中间那个数；若为偶数，是中间两个数的平均数。中位数不受极端值影响。
  • 众数：一组数据中出现次数最多的数叫众数。一组数据可能有多个众数，也可能没有众数（每个数据出现次数一样时）。
  • 方差：方差衡量数据的波动（离散）程度，s² = [(x₁−x̄)² + (x₂−x̄)² + … + (xₙ−x̄)²]/n。方差越小，数据越稳定、波动越小；方差越大，波动越大。比较两个运动员成绩的稳定性就用方差。
  • 四分位数：把数据按大小排好后分成四等份的三个分界点：下四分位数（第一四分位数 Q1，前 25% 的分界）、中位数（Q2）、上四分位数（第三四分位数 Q3，前 75% 的分界）。它反映数据的分布位置，比极值更抗干扰。
重要公式 / 定理
平均数 x̄ = (x₁ + x₂ + … + xₙ)/n；加权平均 x̄ = Σ(xᵢwᵢ)/Σwᵢ
方差 s² = [(x₁−x̄)² + (x₂−x̄)² + … + (xₙ−x̄)²]/n
方差越小，数据越稳定
典型例题
例 1求数据 3, 5, 5, 7, 8, 10 的平均数、中位数和众数。
平均数 x̄ = (3+5+5+7+8+10)/6 = 38/6 = 19/3（约 6.33）。
中位数：共 6 个数据（偶数个），排好后中间两个数是 5 和 7，中位数 = (5+7)/2 = 6。
众数：5 出现 2 次最多，所以众数是 5。
例 2甲、乙两人各射击 5 次，甲的成绩：8, 9, 10, 9, 9；乙的成绩：7, 10, 9, 8, 10。谁的成绩更稳定？
解：两人平均数都是 9。
甲方差 = [(8−9)²+(9−9)²+(10−9)²+(9−9)²+(9−9)²]/5 = (1+0+1+0+0)/5 = 0.4。
乙方差 = [(7−9)²+(10−9)²+(9−9)²+(8−9)²+(10−9)²]/5 = (4+1+0+1+1)/5 = 1.4。
甲的方差 0.4 < 乙的方差 1.4，所以 甲的成绩更稳定。

第二十四章 函数（初步认识）

24.1 变量与常量　24.2 函数的概念与表示　24.3 函数的图象
核心知识点
  • 变量与常量（回顾加深）：在一个变化过程中数值会变的量叫变量，不变的叫常量。判断一个量是变量还是常量，要看它在所研究的问题中是否发生变化。
  • 函数的概念：有两个变量 x、y，对于 x 的每一个确定的值，y 都有唯一确定的值与之对应，则 y 是 x 的函数，x 是自变量，y 是因变量。判断的关键是"一一对应、唯一确定"。
  • 函数的表示方法：三种常用方法：解析式法（用含自变量的式子表示，如 y = 2x + 1）；列表法（列出自变量与函数值的对应表）；图象法（用坐标系中的图象表示对应关系）。
  • 自变量的取值范围：使函数解析式有意义、符合实际意义的所有 x 的取值。整式型的取全体实数；分式型分母不能为 0；二次根式型被开方数 ≥ 0；实际问题还要考虑实际背景。
  • 函数的图象：把自变量与函数值的每一对值作为点的坐标，描出对应的点，这些点组成的图形就是函数图象。画图步骤：列表 → 描点 → 连线。从图象上可以直观看出函数的变化趋势。
重要公式 / 定理
函数判断标准：对 x 的每个确定值，y 有唯一确定值对应
自变量的取值范围：分母 ≠ 0；被开方数（偶次根式）≥ 0
图象画法：列表 → 描点 → 连线
典型例题
例 1求函数 y = 1/(x − 3) 的自变量 x 的取值范围。
解：分母不能为 0，即 x − 3 ≠ 0，所以 x ≠ 3。
例 2已知函数 y = 2x − 1，当 x = 3 时，求 y 的值；当 y = 5 时，求 x 的值。
解：x = 3 时，y = 2×3 − 1 = 5；
y = 5 时，5 = 2x − 1，解得 x = 3。
