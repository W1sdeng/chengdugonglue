小小建筑师

生活中的数学（选做）——度量长宽比 · 画平面结构图 · 电子产品屏幕大小

作业要求：测量家中某个房间（或物品）的长和宽，计算长宽比，画出平面结构图；研究手机、平板、电视屏幕"尺寸"背后的数学，把理论计算值与产品介绍的实际数值作对比。

一、项目简介

建筑师的图纸里藏着数学！我要当一回小小建筑师：拿起卷尺，量一量我家房间的长和宽，算出面积和长宽比，把房间的平面图画到网格纸上；再研究电子产品屏幕为什么用"英寸"表示大小，用勾股定理算一算屏幕到底有多宽、多高，并和产品介绍对比，看数学算得准不准。

四、电子产品屏幕案例

知识：手机、平板、电视的屏幕"尺寸"指屏幕对角线的长度，单位是英寸（inch），1 英寸 = 2.54 厘米。
屏幕是长方形，由勾股定理得：对角线² = 宽² + 高²，即 对角² = 宽² + 高²。

实例 1：手机（标称 6.7 英寸，长宽比 19.5 : 9）

设高 = 9k，宽 = 19.5k（k 是比例单位）
对角² = (19.5k)² + (9k)² = 380.25k² + 81k² = 461.25k²
对角 = 6.7 英寸 → 461.25k² = 6.7² = 44.89 → k² ≈ 0.0973 → k ≈ 0.312 英寸
宽 ≈ 19.5 × 0.312 ≈ 6.08 英寸 ≈ 15.5 cm
高 ≈ 9 × 0.312 ≈ 2.81 英寸 ≈ 7.1 cm

实例 2：平板（标称 10.9 英寸，长宽比 3 : 2）

设高 = 2k，宽 = 3k
对角² = (3k)² + (2k)² = 9k² + 4k² = 13k²
对角 = 10.9 英寸 → 13k² = 10.9² = 118.81 → k² ≈ 9.139 → k ≈ 3.023 英寸
宽 ≈ 3 × 3.023 ≈ 9.07 英寸 ≈ 23.0 cm
高 ≈ 2 × 3.023 ≈ 6.05 英寸 ≈ 15.4 cm

实例 3：电视（标称 55 英寸，长宽比 16 : 9）

设高 = 9k，宽 = 16k
对角² = (16k)² + (9k)² = 256k² + 81k² = 337k²
对角 = 55 英寸 → 337k² = 55² = 3025 → k² ≈ 8.976 → k ≈ 2.996 英寸
宽 ≈ 16 × 2.996 ≈ 47.9 英寸 ≈ 121.7 cm
高 ≈ 9 × 2.996 ≈ 27.0 英寸 ≈ 68.5 cm

六、数学知识运用提示

1. 度量与单位：会读米尺、换算单位（1 m = 100 cm，1 英寸 = 2.54 cm）。
2. 面积计算：长方形面积 = 长 × 宽。
3. 比例与比值：长宽比表示图形"扁"还是"方"；按比例画图。
4. 勾股定理：直角三角形两直角边（宽、高）的平方和等于斜边（对角线）的平方。
5. 估算与开平方：用平方表估算 k 的大小，体会"理论值"与"实际值"的误差。

七、思考题

思考题 1：为什么手机屏幕用"对角线"的长度表示大小，而不用宽或高？
思考题 2：长宽比 19.5 : 9 的手机和长宽比 3 : 2 的平板，同样对角线时谁更"修长"？长宽比对观看影视画面有什么影响？
思考题 3：你量出的房间长宽比是多少？和电视机屏幕（16 : 9）比，谁的比值更接近 1？你从中发现什么规律？
